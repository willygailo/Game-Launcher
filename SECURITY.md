# Security Policy & Compliance Guidelines

## 🛡️ Ban Safety & Non-Tampering Compliance

Precision Aim operates strictly within system-level device parameters using standard Android ADB developer APIs via **Shizuku**.

- **No Process Memory Injection**: We do not read or write into third-party app or game memory space.
- **No Game File Modification**: We do not patch APK files, game OBBs, or internal game configuration files.
- **No Cheat Capabilities**: Features like aimbot, macro execution, recoil elimination, or anti-cheat bypassing are strictly out of scope and prohibited.

---

## 🐛 Reporting Security Vulnerabilities

If you discover a security issue or elevated privilege vulnerability:

1. **Do NOT open a public GitHub issue.**
2. Email details directly to the project maintainers or submit via private vulnerability reporting.
3. Include detailed steps to reproduce, affected Android versions, and impact analysis.
